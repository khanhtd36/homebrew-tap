# khanhtd36/homebrew-tap

Personal Homebrew tap for my forks of upstream projects.

```
brew tap khanhtd36/tap
brew install lazygit-khanhtd36
```

## Formulae

- `lazygit-khanhtd36` — [khanhtd36/lazygit](https://github.com/khanhtd36/lazygit), installs the binary as `lazygit-khanhtd36` so it can live alongside the upstream `lazygit` formula.
